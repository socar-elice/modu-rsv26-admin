# 320_제휴상품상세

> **파일**: `320_제휴상품상세.html`
> **타이틀**: 제휴상품상세 - 모두의주차장 관리자
> **경로**: 제휴 관리 > 제휴주차장 관리 > 제휴상품상세

---

## 1. 페이지 개요

300에서 생성한 제휴 주차권 상품의 상세 정보를 **읽기전용**으로 조회하는 페이지이다. 300(생성 폼)과 동일한 섹션 구조를 가지지만, 모든 입력 필드가 `readonly` 또는 `disabled` 상태이다. 상단에 판매 상태 배지(판매중)가 표시되며, "수정하기" 버튼으로 편집 모드 전환이 가능하다.

## 3. 300 대비 차이점

| 항목 | 300 (생성) | 320 (상세) |
|------|-----------|-----------|
| 필드 상태 | 편집 가능 | 모두 readonly / disabled |
| 상단 버튼 | 취소 / 생성하기 | 목록 / 수정하기 |
| 상태 배지 | 없음 | `status-badge--active` (판매중) |
| 이벤트 스케줄 | 없음 | 아코디언으로 조회·관리 가능 |
| 이벤트 스케줄 등록 모달 | 없음 | 있음 |
| 판매정책 모드 선택 | 클릭 전환 가능 | 활성 모드만 표시 (cursor:default) |

## 4. 페이지 구조

### 4.1 기본 정보 섹션

300과 동일한 필드 구성. 모든 필드가 읽기전용이며 Mock 데이터가 채워져 있다.

- 주차권 유형: "당일권" (disabled select)
- 주차권 이름: "당일권"
- 판매 시작일: 2026-01-01
- 상품 키워드: "실외" 체크됨
- 등

### 4.2 이벤트 스케줄 섹션 (`#sectionEventSchedule`)

300에는 없는 **320 전용 섹션**이다.

#### 아코디언 구조

- **헤더**: 클릭 시 접기/펼치기 (`.es-section.open` 토글)
  - 배지: 적용 0 / 예정 0 / 전체 0
  - "이벤트 스케줄 등록" 버튼
  - 안내 텍스트: "기본 판매정책 및 정기휴무보다 우선 적용"
- **바디**: 이벤트 테이블 또는 빈 상태 표시

#### 이벤트 스케줄 테이블 (`#eventScheduleTable`)

| 컬럼 | 설명 |
|------|------|
| 상태 | 적용중 / 예정 / 종료 |
| 적용기간 | 시작일 ~ 종료일 |
| 적용일수 | 기간 내 일수 |
| 변경 가격 | 이벤트 가격 |
| 변경 수량 | 이벤트 수량 |
| 등록일시 | 등록 시점 |
| 등록자 | 등록한 관리자 |
| 메모 | 말줄임 표시 |
| 액션 | 수정 / 삭제 버튼 |

#### 이벤트 스케줄 등록 모달

- 오버레이 + 다이얼로그 구조
- 입력 필드: 적용 기간, 변경 가격, 변경 수량, 메모
- 기간 중복 시 경고 박스(`.warning-box`) 표시
- 확인 다이얼로그(`.confirm-dialog`): 삭제 확인 등

### 4.3 요금 설정 섹션

300과 동일한 구조이나 모든 값이 readonly.

- 정산비율: 70% (readonly)
- 요일별 판매정책: 월~금 5,000원 / 토~일 7,000원 (readonly)
- 공휴일: 10,000원 (readonly)
- 옵션 가격정책: 모두 0원 / OFF (disabled)

### 4.4 안내메시지 설정

300과 동일한 구조이나 모든 값이 readonly.

- 안내사항: "주차장 이용 시 주차권을 반드시 제시해 주세요."
- 구매전 주의사항: "주차 공간이 한정되어 있어 조기 마감될 수 있습니다."
- 구매후 주의사항: "입차 후 주차권 시간 내 출차하지 않을 경우 추가 요금이 발생합니다."
- 메시지 타입: KAKAO (disabled)
- 템플릿: 25008 (기계식아님)
- POSITION: "충주휴게소 마산방향 주차장"
- TICKET_NOTICE: "입차 시 차량번호가 자동으로 인식됩니다..."

### 4.5 장기권 전용 섹션

300과 동일한 구조. 장기권 유형 선택 시에만 표시되며 모든 값이 readonly.

## 6. 페이지 고유 스타일

| 클래스 | 용도 |
|--------|------|
| `.status-badge` | 판매 상태 배지 (active / inactive) |
| `.es-header`, `.es-body` | 이벤트 스케줄 아코디언 |
| `.es-badge` | 이벤트 상태 배지 (active / scheduled / total) |
| `.event-table` | 이벤트 스케줄 테이블 |
| `.modal-overlay`, `.modal-dialog` | 등록/확인 모달 |
| `.warning-box` | 기간 중복 경고 |
| `.btn--ghost`, `.btn--ghost-danger` | 수정/삭제 액션 버튼 |
| `.empty-state` | 이벤트 없을 때 빈 상태 |
