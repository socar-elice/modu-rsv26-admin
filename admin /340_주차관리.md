# 340_결제주차권관리

> **파일**: `340_결제주차권관리.html`
> **타이틀**: 주차관리 - 결제주차권관리 | 모두의주차장 관리자
> **기술스택**: React 18 + Babel (브라우저 인라인 변환)

---

## 1. 페이지 개요

결제 완료된 주차권 목록을 검색·조회하고, 개별 주차권의 상세 정보를 사이드 패널에서 확인·처리하는 관리 페이지이다. React SPA로 구현되어 있다.

---

|------|----------|

## 3. 페이지 구조

### 3.1 검색 필터 카드 (`.filter-card`)

| 필터 항목 | 타입 | 설명 |
|-----------|------|------|
| 주차장명 | select (`.filter-select`) | 주차장 목록에서 선택 |
| 상품유형 | select | 정기권/일반권/일반공유/거주자공유/단기권 |
| 차량번호 | text (`.filter-input`) | 차량번호 직접 입력 |
| 이용상태 | 칩 버튼 그룹 (`.status-chip`) | 이용대기/이용가능/이용중/이용종료 |
| 결제일 | date range (`.filter-date`) | 시작일 ~ 종료일 |
| 빠른선택 | 버튼 그룹 (`.quick-btn`) | 오늘/1주/1개월/3개월 등 |

### 3.2 검색 결과 테이블 (`.data-table`)

| 컬럼 | 클래스 | 설명 |
|------|--------|------|
| 차량번호 | `.td-vehicle` | 차량번호 + 웹할인 아이콘 |
| 주차장명 | `.td-parking` | 주차장 이름 |
| 상품유형 | `.product-type-tag` | 정기권/일반권/공유/단기 태그 |
| 상품명 | `.td-product` | 상품 이름 |
| 이용기간 | `.td-datetime` | 시작~종료 |
| 결제상태 | `.payment-status` | 결제완료/결제취소 |
| 이용상태 | `.entry-status` | 이용대기/이용가능/이용중/이용종료 |
| 판매금액 | `.td-amount` | 금액 (우측 정렬) |

### 3.3 페이지네이션 (`.pagination-wrapper`)

- 5페이지 단위 윈도우
- 처음(«) / 이전(‹) / 번호 / 다음(›) / 마지막(»)

### 3.4 상세 패널 (`.detail-panel`)

테이블 행 클릭 시 우측에서 슬라이드-인되는 사이드 패널.

#### Quick Summary (`.quick-summary`)

- 차량번호 + 결제상태
- 주차장명
- 이용기간 (시작 → 종료)
- 판매금액

#### 섹션 카드 (`.section-card`)

아코디언 접기/펼치기 가능한 카드 형태로 구성:

| 섹션 | 내용 |
|------|------|
| 주문 정보 | 결제ID, 구매자명, 연락처, 안심번호, 차종 등 |
| 항공편 정보 | 출발편, 도착편, 도착터미널 |
| 상품 정보 | 상품유형, 상품명, 이용기간, 이용상태 |
| 입출차 처리 | 입차/출차 시간 입력 폼 + 처리 이력 테이블 |
| 결제 정보 | 판매금액, 결제수단, 결제상태 등 |

#### 입출차 처리 폼 (`.entry-form`)

- 입차시간 / 출차시간 datetime 입력
- 입차처리 / 출차처리 버튼
- 처리 이력 테이블 (`.history-table`)

## 4. Mock 데이터

- `PARKING_LOTS`: 3개 주차장 (투루파킹/역삼동/선릉역)
- `DUMMY_VEHICLES`: 31개 주차권 데이터
  - 다양한 상품유형 분포 (정기권/일반권/일반공유/거주자공유/단기권)
  - 결제완료 / 결제취소 상태
  - 입출차 시간 유무에 따른 이용상태 변화

## 5. 주요 상태 뱃지

### 상품유형 태그 (`.product-type-tag`)

| 유형 | 클래스 | 색상 |
|------|--------|------|
| 정기권 | `.pass` | 파란색 |
| 일반공유 | `.share` | 초록색 |
| 거주자공유 | `.resident` | 보라색 |
| 단기권 | `.short` | 주황색 |
| 일반권 | (기본) | 회색 |

### 이용상태 (`.entry-status`)

| 상태 | 클래스 | 색상 |
|------|--------|------|
| 이용대기 | `.waiting` | 슬레이트 |
| 이용가능 | `.available` | 녹색 계열 |
| 이용중 | `.active` | 파란색 |
| 이용종료 | `.done` | 회색 |

### 결제상태 (`.payment-status`)

| 상태 | 클래스 | 색상 |
|------|--------|------|
| 결제완료 | `.completed` | 녹색 |
| 결제취소 | `.cancelled` | 적색 |
