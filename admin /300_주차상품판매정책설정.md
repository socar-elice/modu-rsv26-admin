# 300_주차상품판매정책설정

> **파일**: `300_주차상품판매정책설정.html`
> **타이틀**: 제휴주차권 생성 - 모두의주차장 관리자
> **경로**: 제휴 관리 > 제휴주차장 관리 > 제휴상품생성하기

---

## 1. 페이지 개요

제휴 주차장의 주차권 상품을 신규 생성하는 폼 페이지이다. 주차권 유형(일반권 / 장기권 / 단기권)에 따라 입력 폼과 요금 설정 섹션이 동적으로 전환된다.

## 4. 요금 설정 (일반권 / 단기권)

### 4.1 요금 모드 선택 (`#pricingModeSelector`)

- **요일별 설정** (기본): 월~일 각 요일별 판매금액 / 정산금액 / 판매수량 설정
- **일괄요금 설정**: 선택 요일에 동일 금액·수량 적용

### 4.2 주차장 정산비율

- ID: `settlementRate`
- 기본값: 70(%)
- 정산금액 = 판매금액 × 정산비율 / 100 (자동 계산)

### 4.3 최소이용금액 (`#sectionMinPrice`)

- 단기권일 때만 표시
- 요일별 기본 판매 요금 합산과 비교하여 더 큰 금액 적용

### 4.4 기본 판매정책 (요일별)

| 요일 | 토글 | 판매금액 | 정산금액(자동) | 판매수량 |
|------|------|----------|----------------|----------|
| 월~금 | ON | 5,000원 | 3,500원 | 10 |
| 토~일 | ON | 7,000원 | 4,900원 | 10 |

### 4.5 공휴일 판매정책

- 공휴일: 판매금액 10,000원, 정산금액 7,000원, 수량 10

### 4.6 옵션 가격정책

| 옵션명 | 기본 상태 |
|--------|-----------|
| 추가요금 | OFF |
| 발렛 픽업/전송 | OFF |
| 심야 입차 | OFF |
| 심야 출차 | OFF |

## 5. 요금 설정 (장기권)

장기권 선택 시 일반 요금 섹션이 숨겨지고 `#longTermSections`가 표시된다.

### 5.1 가격 판매정책

| 필드 | ID | 비고 |
|------|----|------|
| 이용요일 | `ltDayBtnGroup` | 월~일 토글 버튼 |
| 최대판매수량 | `ltMaxSalesQty` | |
| 판매금액 | `ltSalePrice` | |
| 정산비율 | `ltSettlementRatio` | % |
| 정산금액 | `ltSettlementAmount` | 자동 계산 (판매금액 × 비율) |

### 5.2 정기권 연장 설정

| 필드 | ID | 비고 |
|------|----|------|
| 연장 가능 여부 | `ltRenewalPossible` | 토글 스위치, 가능/불가능 |
| 연장 단위 기간 | `ltRenewalUnit` | 개월 |
| 연장 판매금액 | `ltRenewalPrice` | 원 |
| 정산비율 | `ltRenewalRatio` | % |
| 연장 정산금액 | `ltRenewalSettlement` | 자동 계산 |

## 6. 안내메시지 설정

일반권/단기권과 장기권 각각 별도 안내메시지 섹션이 존재한다.

### 6.1 공통 필드

| 필드 | 최대 글자수 |
|------|-------------|
| 안내사항 | 500자 |
| 구매전 주의사항 | 300자 |
| 구매후 주의사항 | 300자 |
| 안내메시지 타입 | KAKAO / SMS |

### 6.2 카카오 템플릿 (일반권)

- 템플릿 ID: `25008` (기계식 아님), `25007` (기계식)
- 변수: `POSITION` (100자), `TICKET_NOTICE` (300자)
- 템플릿 내용 및 미리보기 실시간 렌더링

### 6.3 카카오 템플릿 (장기권)

- 템플릿 ID: `25037` (월정기), `25036` (기계식)
- 변수: `TICKET_NOTICE` (300자)

## 8. JavaScript 주요 로직

| 기능 | 설명 |

| 주차권 유형 변경 | `ticketType` 변경 시 UI 분기(일반/장기/단기) 및 기본값 자동 적용 |
