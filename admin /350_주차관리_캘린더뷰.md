# 350_결제주차권관리_캘린더(월간수요)

> **파일**: `350_결제주차권관리_캘린더(월간수요).html`
> **타이틀**: 주차관리 - 결제주차권관리 캘린더(월간수요) | 모두의주차장 관리자
> **기술스택**: React 18 + Babel (브라우저 인라인 변환)
> **CSS 네임스페이스**: `cal350-`

---

## 1. 페이지 개요

결제된 주차권의 월간 수요를 **캘린더 형태**로 시각화하는 페이지이다. 날짜별 이용상태 분포(이용대기/이용가능/이용중/이용종료)를 한눈에 파악할 수 있으며, 특정 날짜 클릭 시 해당일의 주차권 목록을 하단 테이블에서 조회한다.

## 3. 페이지 구조

### 3.1 필터 카드 (`.cal350-filter-card`)

| 필터 항목 | 타입 | 설명 |
|-----------|------|------|
| 조회 범위 | 세그먼트 버튼 (`.cal350-scope-segment`) | 전체주차장 / 내 관리주차장 / 주차장 선택 |
| 주차장 선택 | 멀티셀렉트 (`.cal350-ms`) | "주차장 선택" 모드일 때 활성화 |

#### 멀티셀렉트 컴포넌트 (`.cal350-ms-*`)

- 검색 필터링 (`.cal350-ms-search`)
- 체크박스 리스트 (`.cal350-ms-list`)
- Select All / 선택 해제
- Apply / Cancel 버튼
- Draft 방식 (Apply 전까지 실제 반영 안 됨)
- 선택된 항목 칩 표시 (`.cal350-ms-chip`)
- 외부 클릭 시 Cancel 동작

### 3.2 월 네비게이션 (`.cal350-month-nav`)

- 이전/다음 월 버튼 (`.cal350-month-btn`)
- 현재 월 라벨 (`.cal350-month-label`): "2026년 2월" 형식
- 월 직접 선택 input (`.cal350-month-input`, type=month)
- 상태 범례 (`.cal350-legend`)

### 3.3 캘린더 그리드 (`.cal350-calendar-grid`)

- 7열 CSS Grid (일~토)
- 요일 헤더 (`.cal350-calendar-dow`)
  - 일요일: 빨간색, 토요일: 파란색

#### 셀 (`.cal350-cell`)

| 클래스 | 설명 |
|--------|------|
| `.cal350-cell--today` | 오늘 날짜 강조 |
| `.cal350-cell--selected` | 선택된 날짜 (파란 테두리) |
| `.cal350-cell--empty` | 빈 셀 (해당 월 외) |
| `.cal350-cell--sun` | 일요일 |
| `.cal350-cell--sat` | 토요일 |

#### 셀 내부 구성

```
┌─────────────────┐
│ 3               │ ← 날짜 (.cal350-cell-date)
│ 5건             │ ← 총 건수 (.cal350-cell-total)
│ ■ 이용대기 1    │ ← 배지 (.cal350-badge--before)
│ ■ 이용중 2      │ ← 배지 (.cal350-badge--inuse)
│ ■ 이용종료 2    │ ← 배지 (.cal350-badge--done)
└─────────────────┘
```

| 이용대기 | `.cal350-badge--before` | #64748b | #f8fafc | #94a3b8 |

| 이용중 | `.cal350-badge--inuse` | #2563eb | #f0f4ff | #5b8def |
| 이용종료 | `.cal350-badge--done` | #6b7280 | #f9fafb | #9ca3af |

### 3.5 날짜 선택 시 상세 테이블 (`.cal350-detail-card`)

캘린더에서 날짜 클릭 시 하단에 표시되는 테이블.

| 컬럼 | 설명 |
|------|------|
| 결제번호 | paymentId |
| 회원번호 | memberId |
| 차량번호 | vehicleNumber |
| 주차장명 | parkingLotName |

| 결제상태 | 결제 배지 (`.cal350-pay-badge`) |

## 4. 핵심 비즈니스 로직

### 4.1 주차일 포함 판정 (`isTicketOnDate`)

```
조건: usageStart < (D+1일 00:00) AND usageEnd > (D일 00:00)
예외: usageEnd가 정확히 D일 00:00이면 D에 포함하지 않음 (24:00 경계값)
```

### 4.2 집계 제외 상태

다음 상태의 주차권은 캘린더 집계에서 **제외**된다:
- 취소완료
- 환불신청
- 환불완료

### 4.3 상태별 집계 (`countByStatus`)

각 날짜별로 이용대기 / 이용가능 / 이용중 / 이용종료 건수를 세어 배지에 표시한다.

## 5. Mock 데이터

- `MOCK_TICKETS`: 22개 주차권 (2026-01, 2026-02)
  - 다양한 이용기간 분포 (당일 ~ 6일)
  - 경계값 케이스 포함 (24:00 = 다음날 00:00)
  - 제외 상태 포함 (취소완료/환불신청/환불완료)
- `MOCK_PARKING_LOTS`: MOCK_TICKETS에서 자동 파생
- `MOCK_MY_PARKING_LOTS`: 내 관리 주차장 필터 (투루파킹/역삼동)

## 6. 디자인 특징

### 톤다운 컬러 팔레트

- 뉴트럴(그레이) 기반 + 이용중만 블루 포인트 컬러
- 배지: 옅은 틴트 배경 + 좌측 보더 + 뮤트 텍스트
- WCAG AA 4.5:1 이상 대비 확보

### 로딩 상태

- `.cal350-loading`: 반투명 오버레이 + 스피너 애니메이션

### 빈 상태

- `.cal350-empty`: 날짜 미선택 시 안내 메시지 + 아이콘
