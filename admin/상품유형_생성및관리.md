> 관련 화면: `300_주차상품판매정책설정.html` (생성), `320_제휴상품상세.html` (상세/수정)

## 1. 상품유형 분류 체계

주차권 유형은 **3개 대분류**, **13개 세부유형**으로 구성된다.

|------|------|:---:|:---:|
| **당일권** | 당일 1일 이용 | 00:00 ~ 23:59 | 1일 / 1일 |
| **주간권** | 주간 시간대 이용 | 05:00 ~ 22:00 | 1일 / 7일 |
| **오전권** | 오전 시간대 이용 | 00:00 ~ 12:00 | 1일 / 1일 |
| **오후권** | 오후 시간대 이용 | 12:00 ~ 23:59 | 1일 / 1일 |
| **야간권** | 야간 시간대 이용 | 18:00 ~ 23:59 | 1일 / 1일 |
| **심야권** | 심야 시간대 이용 (익일 포함) | 19:00 ~ 07:00 | 1일 / 1일 |
| **시간권(시간대)** | 지정 시간대 내 N시간 이용 | 00:00 ~ 23:59 | 1일 / 1일 |
| **시간권(입차기준)** | 입차 시점부터 N시간 카운트 | 주차시간 설정 불필요 | 1일 / 1일 |
| **연박권** | 연속 복수일 이용 | 00:00 ~ 23:59 | 2일 / 14일 |

### 1-2. 장기권 (정기/월 단위 이용)

| 유형 | 설명 | 기본 주차시간 | 최소/최대 이용일 |
|------|------|:---:|:---:|

### 1-3. 단기권

- **시간권(시간대)**: 주차가능 시작~종료시간 범위 내에서 설정된 시간만큼 이용 가능

### 3-2. 판매정책 기간 관리

기존 "판매 시작일/종료일" 단일 필드 대신 **기간 목록**을 관리한다.

- 초기값: 1건 (시작일 미지정 ~ 2099-12-31)
- **기간추가** 버튼 → 시작일·종료일 입력 → 저장/취소
- 각 기간 항목에 **삭제** 버튼
- 검증: 시작일·종료일 모두 필수, 종료일 ≥ 시작일

## 4. 요금 설정

### 4-1. 주차장 정산비율 (별도 섹션)

일반권/단기권에서 별도 카드로 표시되며, 기본값 **70%**. 정산금액 계산의 기준이 된다.

```
정산금액 = 판매금액 × 정산비율(%) / 100
```

### 4-2. 일반권/단기권 — 요금 설정 모드

두 가지 모드 중 하나를 선택하여 요금을 설정한다.

#### (A) 요일별 설정 (기본)

| 요일 | 활성화 토글 | 판매금액 | 정산금액 (자동) | 판매수량 |
|------|:---:|---:|---:|---:|
| 월~금 | ON/OFF | 5,000 | 3,500 | 10 |
| 토~일 | ON/OFF | 7,000 | 4,900 | 10 |

별도 **공휴일 판매정책** 카드:

| 공휴일 | 활성화 토글 | 판매금액 | 정산금액 (자동) | 판매수량 |
|--------|:---:|---:|---:|---:|
| 공휴일 | ON/OFF | 10,000 | 7,000 | 10 |

#### (B) 일괄요금 설정

- **판매 요일** 버튼으로 적용할 요일 선택 (월~일 토글)
- 인라인 필드: 판매금액 / 주차장 정산금액 (자동) / 판매수량
- **공휴일** 체크박스 토글 → ON 시 별도 판매금액 / 정산금액 / 판매수량 입력

### 4-3. 최소이용금액 (단기권 전용)

사용자가 선택한 날짜에 해당하는 요일별 기본 판매 요금의 **합산**과 최소이용금액을 비교하여 **더 큰 금액**을 상품금액으로 결정한다.

### 4-4. 장기권 — 가격 판매정책

| 필드 | 설명 |
|------|------|
| 이용요일 | 월~일 버튼 토글 |
| 최대판매수량 | 숫자 입력 |
| 판매금액 | 원 단위 입력 |
| 정산비율 | % 입력 |
| 정산금액 | 자동 계산 (판매금액 × 정산비율) |

### 4-5. 장기권 — 정기권 연장 설정

| 필드 | 설명 |
|------|------|
| 연장 가능 여부 | 토글 (가능/불가능) |
| 연장 단위 기간 | N개월 (연장 가능 시 활성) |
| 연장 판매금액 | 원 단위 (연장 가능 시 활성) |
| 정산비율 | % (연장 가능 시 활성) |
| 연장 정산금액 | 자동 계산 |

### 4-6. 옵션 가격정책

**단기권만 활성화**되며, 나머지 유형에서는 비활성 상태로 "준비중" 배지가 표시된다.

| 옵션 항목 | 토글 | 판매금액 | 정산금액 |
|-----------|:---:|---:|---:|
| 추가요금 | ON/OFF | 0 | 0 |
| 발렛 픽업/전송 | ON/OFF | 0 | 0 |
| 심야 입차 | ON/OFF | 0 | 0 |
| 심야 출차 | ON/OFF | 0 | 0 |

## 8. 주요 비즈니스 규칙 요약

1. **유형 선택 즉시** 기본값(주차시간, 이용일 수, 주차권 이름)이 자동 세팅된다.
2. **정산금액**은 항상 `판매금액 × 정산비율 / 100`으로 자동 계산되며 직접 수정 불가(readonly)이다.
3. **옵션 가격정책**과 **고객 추가정보 입력**은 단기권에서만 활성화된다.
4. 장기권 선택 시 기존 요일별/일괄 요금 섹션이 숨겨지고 **정기권 전용 섹션**이 표시된다.
5. 안내메시지 타입을 SMS로 변경하면 카카오 템플릿 관련 UI가 모두 숨겨진다.
6. **예매 설정**에 따라 하위 필드가 전환된다: 예매불가 → 판매 시작/종료시간, 예매가능 → 구매가능 시작일/마감일.
7. **판매정책 기간**은 시작일~종료일 쌍의 목록으로 관리되며, 추가/삭제가 가능하다. 초기값은 종료일 2099-12-31.
8. 구매가능 시작일/마감일은 **시간 또는 일 단위** 전환이 가능하다.
